# PhelpsCookbook

A fun, interactive **recipe cookbook web app** that lets users browse and explore recipes right from the browser. Built with HTML, CSS, and JavaScript.

📦 This project contains:
- A main landing page
- A dynamic recipe list view
- Style assets and visuals
- A modular structure for recipes and UI interaction

## ⚡ Features

- 🍲 **Browse recipes**
- 🔍 View recipe details
- 📁 Organized folder structure
- 🎨 Simple, responsive UI
- ✨ Vanilla JavaScript for interaction

---

## 🗂️ Project Structure

```

PhelpsCookbook/
├── assets/           # Images and static assets
├── recipie/          # Recipe data or templates
├── see_recipies/     # UI for displaying recipes
├── index.html        # Main view
├── index.js          # JavaScript logic
├── styles.css        # Custom styling
├── README.md         # Project documentation
└── .gitignore

````

---

## 🛠️ Installation

To run this project locally:

1. **Clone the repo:**
```bash
git clone https://github.com/JTexpo/PhelpsCookbook.git
````

2. **Open the project:**

   * Open `index.html` in your browser
   * Or use a local server for better development workflow

> No build tools or dependencies — just plain HTML, CSS & JS!

---

## 🚀 Usage

Once opened in your browser:

* Browse featured recipes
* Click on any recipe to see more details
* Explore ingredients and instructions

---

## 🧩 How It Works

At a high level:

* `index.html` is the main UI
* `index.js` handles dynamic recipe logic & interactions
* `styles.css` contains responsive visual styles
* Folders like `recipie/` store data or individual component views
